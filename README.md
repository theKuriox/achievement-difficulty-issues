# Achievement Difficulty — Issue Tracker

Report bugs and suggest features for both Achievement Difficulty projects:

- [Fabric mod](https://modrinth.com/mod/achievement-difficulty)
- [Paper plugin](https://modrinth.com/plugin/achievement-difficulty-plugin)

[Open a new issue](https://github.com/theKuriox/achievement-difficulty-issues/issues/new). Please include which edition you use, your Minecraft and mod/plugin versions, what you expected, what happened, and steps to reproduce the problem. Screenshots or relevant error messages help.

This repository is for issue tracking; it does not contain the mod or plugin source code.
